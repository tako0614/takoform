# 策定中の提案

現在の設計対象は[Host API v2](host-api-v2.md)です。Form作者がHTTPで公開した仕様を
Hostが実装するモデルを扱います。公開済みv1は内容を固定して保存し、v2だけの実装も
適合できるようにします。

このディレクトリの文書は、公開済みの規範や実装済みAPIを示しません。
各文書で採用方針、未決事項、公開前の条件を区別します。

[W19の動的Definition取得案](w19-dynamic-definition-retrieval.md)は以前の検討資料です。
v2草案はHostからのDefinition取得やpackage検証を前提にしないため、この案をv2の必須要件として
引き継ぎません。過去の提案本文は判断理由を参照できるよう保持します。
