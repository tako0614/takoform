# このサイトについて {#この-site-について}

Takoformは、Formが定義するリソースをHostが提供するための共通APIとモデルです。このサイトではAPI仕様、Formの説明方法、実装ガイドを扱います。

上部のAPI選択で読む版を切り替えられます。言語の選択は版とは別です。仕様は英語の原文を掲載し、ガイドは日本語と英語で読めます。各仕様ページでは規範と解説を分けて示します。

## 掲載内容 {#この-repository-が扱う範囲}

- Host APIと共通モデル — リソースの識別、要求・応答、操作。
- Form — リソース固有の入力、出力、振る舞いの記述。
- 実装ガイドと例 — 利用者、Form作者、Host・クライアント実装者向け。
- JSON Schema — 公開スキーマを識別子のパスで提供します。

個別Formの利用情報は公開元で、Hostやクライアントの対応状況は利用する製品・環境で確認してください。
